# Meridian Data Utilities

A lightweight collection of Python utilities designed to support log processing, data validation, and automated reporting.

## Overview

Meridian Data Utilities provides simple command-line tools for analysing structured log files and generating summary reports.

The project was originally developed as a collection of personal automation scripts and later consolidated into a single repository.

## Features

- CSV and JSON log parsing
- Automated data validation
- Event timestamp normalisation
- Summary report generation
- Basic file integrity checking
